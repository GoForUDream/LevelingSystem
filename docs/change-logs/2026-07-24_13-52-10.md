# Calendar Scrolling and Font CSP Repair

## What Changed

- Replaced the external Google Fonts stylesheet with locally bundled Oxanium font files.
- Kept the production Content Security Policy restricted to same-origin styles and fonts.
- Changed calendar navigation to calculate a deterministic fixed-column scroll position.
- Made the Today action center the current date instead of the middle of the current month.
- Added vertical-wheel horizontal scrolling for the calendar.
- Preserved normal vertical scrolling inside day task lists.
- Added unit coverage for centered calendar column positioning and start-boundary clamping.

## Why

The production CSP correctly rejected the Google Fonts stylesheet because `style-src`
and `font-src` permit only same-origin resources. Self-hosting the font removes the
violation without weakening the policy.

Calendar navigation previously delegated to the virtualizer and treated Today as a
month-level destination. Using the calendar's fixed column width makes navigation
independent of virtual item mount timing and allows Today to target the exact day.
Wheel handling restores an intuitive desktop path even though the horizontal
scrollbar is visually hidden.
